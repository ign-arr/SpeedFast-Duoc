# SpeedFast - Semana 8

Proyecto que permite registrar, consultar, modificar y eliminar pedidos,
repartidores y entregas mediante ventanas.
Los datos se guardan en MySQL.

## Cómo ejecutar

1. Abrir el proyecto.
2. Iniciar MySQL.
3. Ejecutar `sql/speedfast_db.sql`.
4. Ejecutar `main.Main`.
